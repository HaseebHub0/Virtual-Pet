# Virtual Pet Program

This is a simple Python-based virtual pet program where users can interact with their pet by feeding, playing, or letting it sleep. The pet has attributes like happiness, hunger, health, energy, and age, which change as the user interacts with it. If any attribute gets too low or high, the pet will "pass away."

## Features

- **Feed the pet**: Reduces hunger and increases health.
- **Play with the pet**: Increases happiness, but consumes energy.
- **Sleep**: Restores energy and increases happiness.
- **Check pet's status**: Displays current pet stats like happiness, hunger, health, energy, and age.
- **Game over conditions**: The pet dies if hunger exceeds 100, happiness is 0, or health is 0.
